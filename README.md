# 💰 Personal Expense Tracker and Analyzer

**Course:** CSC 4162. Programming in Python  
**Project:** Mid-Term Group Project (Team 3)  
**Semester:** Fall 2026-27

---

## 📌 1. Project Overview

This application is a robust desktop tool designed to help users track and analyze their daily expenses. It features a Graphical User Interface (GUI) built with **Tkinter**, persistent data storage using **JSON**, and statistical analysis using **NumPy**. 

The project is highly modular, following **Object-Oriented Programming (OOP)** principles, with built-in validation and exception handling to ensure the app never crashes due to invalid user input.

---

## ⚙️ 2. System Requirements & Setup

### Required Python Version:
*   **Python 3.10 or higher** is highly recommended. *(The foundation of this project was developed and tested on Python 3.12.3).*

### Dependencies:
*   `numpy` (For statistical analysis)
*   `tkinter` (For the GUI)
*   `json` (Built-in, for file handling)
